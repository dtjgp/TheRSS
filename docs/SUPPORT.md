# 支持与问题反馈

使用问题可先查看 [使用说明](USER_GUIDE.md) 和 [更新恢复说明](LOCAL_UPDATE.md)。

普通错误通过 [TheRSS Issues](https://github.com/dtjgp/TheRSS/issues) 反馈，请提供应用版本、macOS 版本、复现步骤、预期行为和实际结果。涉及来源时，请保留来源名称、错误状态和发生时间；第三方服务的暂时不可用不等于研究数据已经丢失。

请勿在公共问题中粘贴 API key、完整私人研究背景、数据库文件或未公开论文。安全问题按 [安全报告说明](SECURITY.md#vulnerability-reporting) 处理。

## 常见恢复路径

- Search 不可用：检查问题、来源选择和执行方式旁边的提示。
- 部分来源失败：保留成功结果，从 Search details 重试未完成来源。
- 本地结果不再存在：重新进行本地查找，或显式打开原始网站。
- 保存的分析过时：检查来源变化提示，再决定是否重新分析。
- 模型连接失败：查看对应字段错误和 Connection test details；测试不会替你保存草稿。
- 更新后无法启动：使用安装回执定位上一版应用及数据库备份，按更新说明恢复。

本轮原生发布目标是 macOS 26+ 的 AppKit 体验。保留的 Web 兼容路径有独立测试；旧系统的实际使用不能仅凭新系统截图或兼容模式测试宣称已经完成整机验收。
