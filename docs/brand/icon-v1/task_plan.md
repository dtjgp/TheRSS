# Task Plan: TheRSS Icon v1

## Goal

Create one distinctive, low-AI-feel app icon concept that fits TheRSS's existing editorial visual system and remains recognizable at small macOS icon sizes.

## Phases

- [x] Phase 1: Inspect product identity, existing UI language, and packaging constraints.
- [x] Phase 2: Define the icon concept and generation constraints.
- [x] Phase 3: Generate and inspect the first candidate.
- [x] Phase 4: Save the selected preview and document iteration choices.

## Key Questions

1. Does the mark communicate curated research discovery without relying on AI clichés?
2. Does its silhouette remain legible when reduced to dock and Finder sizes?
3. Does it feel native to the forest, paper, yellow, and signal-red product palette?

## Decisions Made

- Use an editorial research-signal metaphor instead of a brain, robot, neural mesh, sparkles, or glossy AI gradient.
- Reuse the live UI palette: forest green, warm paper, mustard yellow, signal red, and near-black ink.
- Produce a standalone concept asset first; do not replace package or application icons until the user approves the direction.

## Errors Encountered

- None.

## Review Notes

- Candidate 1 fits the palette and avoids AI tropes, but the curled page and layered shadows make it read too much like a generic document/folder utility.
- The next iteration will preserve the core metaphor while flattening the construction into a stronger editorial mark.
- Candidate 2 removes the curl and depth, remains legible at 64 px, and is retained as the v1 approval candidate.
- The first candidate exposed opaque black outer corners. A background-extraction pass replaced only the outer corners with a genuine alpha channel.

## Status

**Complete** - The 1024 px transparent PNG candidate is saved for user review; application integration intentionally remains unmodified pending approval.
