# TheRSS Icon v1 Design Brief

## Purpose

Represent TheRSS as a calm, deliberate research-discovery tool: a daily editorial signal selected for one researcher, with local ownership and visible provenance.

## Core Metaphor

**An editorial research signal:** a paper index card and a single signal marker, composed like a small independent journal's imprint.

## Palette

- Forest: `#183F34`
- Paper: `#F2EEE5`
- Mustard: `#F0C44F`
- Signal red: `#D84A2F`
- Ink: `#1C211D`

## Composition

- rounded macOS-style square with a deep-forest field;
- one bold warm-paper card or folded page at the center;
- one mustard index/tab element;
- one restrained red signal dot or seal;
- no words, letters, numbers, or micro-details.

## Approval Boundary

This first asset is a visual candidate only. Packaging and application references should be changed only after the direction is approved and after platform-size exports are generated and inspected.

## Generated Candidate

- File: `assets/brand/therss-icon-v1.png`
- Format: PNG, 1024 x 1024, transparent outer corners
- Small-size check: legible at 64 x 64
- Generation path: built-in image generation, followed by a targeted flattening pass and a transparent-corner correction

## Final Prompt Summary

Create a restrained, flat editorial app icon for a local-first academic discovery inbox. Place a warm-paper research card, mustard index tab, and one signal-red marker on a deep-forest field. Use large vector-like shapes, balanced asymmetry, and subtle print tactility. Avoid all AI clichés, glossy gradients, 3D depth, generic RSS arcs, words, and tiny details.
