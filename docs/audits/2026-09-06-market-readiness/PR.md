# Complete native research workflows and evidence controls

Native feedback, compact reading and local search previously disrupted navigation or lost context. This change keeps the research query directly editable, removes redundant read/expand/open steps, filters local lookup while typing, stabilizes notices, preserves reading/selection state, and adds validated local Saved/session/analysis navigation. Source selection, settings recovery and numeric Analytics tables retain their existing controls and evidence boundaries. Sources now compares its stored source reads with per-source Discover history and shows the latest valid observation, with timestamp, context and bounded reason. Failed and partial results are explicit; no matches is a normal query outcome. Persistent global source-attention prompts are removed, with feedback kept on Sources and the current search. The project UI skill adapts pinned Apple principles to AppKit and the Web fallback. A reproduced Command-Q re-entry race and full-bundle installer verification are also addressed.

Official source endpoints replace unstable mirrors for OpenAI, three news lists and CNBC. Feed shape, calendar dates, same-origin redirects and access-denied enrichment fail explicitly while retaining cache. NCPSD publication months remain month-only in ranking, display and analysis. Saved can explicitly adopt a newer local Discover snapshot without changing its saved time or immutable analysis history. Generic analysis v2 separates update dates and popularity from evidence; paper analysis v3 prohibits invented locators and stronger novelty claims, with historical versions preserved.

Validation: `npm run check` passes 687 main and 104 AppKit tests (overlapping suites); eight desktop cases pass, and packaged plus exact installed native suites each pass 14 workflow groups. All 16 build outputs match the package and 11 real-data tables match the immediate installation backup. Fifteen targeted local-navigation cycles passed. One test-window close was not reproduced in traced, repeated or installed verification; its cause remains unconfirmed and diagnostic tracing is retained. No dependency, global skill or SQLite schema changes. The new source projection is covered by immutable-history regressions and native failed/partial/no-match fixtures.

The bounded live baseline ran six searches (469 returned records) and four analysis attempts. Three analyses completed: two passed this sample's source review, one overstated evidence; one attempt timed out. Assistant Top-10 labels reveal weak direct relevance on compound constraints. Human precision and recall are unmeasured, and the new paper v3 guard has offline regression coverage but no live rerun within this budget. See `docs/audits/2026-09-07-source-quality/REPORT.md` for that baseline and `docs/audits/2026-09-07-direct-interaction/REPORT.md` for the direct-interaction changes, and `docs/audits/2026-09-07-apple-design-status/REPORT.md` for current source-feedback validation; code tests are not quality guarantees.
