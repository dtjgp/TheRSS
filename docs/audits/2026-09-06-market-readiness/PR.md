# Complete native research workflows and evidence controls

Native feedback, compact reading and local search previously disrupted navigation or lost context. This change stabilizes notices, preserves reading/selection state, adds validated local Saved/session/analysis navigation, and improves source selection, settings recovery and numeric Analytics tables. A reproduced Command-Q re-entry race and full-bundle installer verification are also addressed.

Official source endpoints replace unstable mirrors for OpenAI, three news lists and CNBC. Feed shape, calendar dates, same-origin redirects and access-denied enrichment fail explicitly while retaining cache. NCPSD publication months remain month-only in ranking, display and analysis. Saved can explicitly adopt a newer local Discover snapshot without changing its saved time or immutable analysis history. Generic analysis v2 separates update dates and popularity from evidence; paper analysis v3 prohibits invented locators and stronger novelty claims, with historical versions preserved.

Validation: `npm run check` passes 669 main and 96 AppKit tests (overlapping suites); eight desktop cases pass, and packaged plus exact installed native suites each pass 13 workflow groups. All 16 build outputs match the package and 11 real-data tables match the immediate installation backup. No dependency or SQLite schema changes.

The bounded live baseline ran six searches (469 returned records) and four analysis attempts. Three analyses completed: two passed this sample's source review, one overstated evidence; one attempt timed out. Assistant Top-10 labels reveal weak direct relevance on compound constraints. Human precision and recall are unmeasured, and the new paper v3 guard has offline regression coverage but no live rerun within this budget. See `docs/audits/2026-09-07-source-quality/REPORT.md` and `verification.json`; code tests are not quality guarantees.

Version 0.3.0 remains an unsigned local candidate. NBER is failed and NCPSD partial, with cache behavior preserved. Independent human acceptance is pending.
