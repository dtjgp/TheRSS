## Capability Contract

### A1 项目级 Apple 设计参考

将目的、用户控制、熟悉性、简洁、及时反馈、空间一致性、系统排版及辅助显示偏好转为 TheRSS 的检查项。修改项目 skill 的 renderer-only 陈述，使其准确区分原生 AppKit 主界面与 Web 回退；AGENTS.md 将所有相关 UI 工作路由到该项目规范。

保留现有 3/2/7 设计选择、用户暂通过的人工验收决定、数据/权限/证据约束。明确拒绝机械删除必要标签、全部透明化、装饰性弹跳、用 Web 动画替换原生滚动/分栏，以及为“可中断动画”破坏模型调用并发规则。

### A2 最新来源观察

Dashboard 的来源状态只读地比较 source_run 和每个来源最近一次 Discover 终态，选择记录时间最新者。Discover 的 not_searched 和 canceled 不作为来源失效证据；没有观察时为 idle。源内容/旧 Today 记录的 healthy + 0 仍映射为 no_results。

保留来源状态、观察时间、错误说明，并注明来自来源读取还是 Discover 搜索。Discover 时间使用其已存储的会话时间，不编造逐来源完成时间；无匹配结果不等同于来源失效。时间相同时保留 source_run 的明确来源读取状态，历史重放不能覆盖更新记录。

旧数据在升级后立即通过同一读模型得到正确状态，无需再次访问站点。现有历史记录、缓存、收藏/分析及统计不写回、不迁移。异常说明继续有界并过滤凭据/私有路径。

### A3 明确且就近的反馈

移除原生与 Web 侧栏常驻的 N sources need attention；Web Discover 顶栏只说明搜索用途，跨查询的旧状态留在 Sources；当前检索已有明确的搜索结果状态、详情和针对未完成来源的重试入口。

Sources 页面按最新观察区分失败与部分数据，筛选改为明确的 Failed or partial。来源详情优先呈现记录状态、时间、观察上下文和原因；来源优先级等辅助元数据移到后面。缓存内容与最近搜索的观察分别说明，不能让“本次无匹配”误导成“缓存为空”，也不能把旧记录说成实时可用性。

保留直接编辑、单击/Return 打开、250 ms 本地查询防抖及过时响应保护。AppKit 负责按下反馈、滚动、分栏和弹窗；本轮没有证据要求增加额外动效。

## Uncertainty Reducer

- UI：原生/兼容 fixture 验证无全局 attention，来源上下文、时间和错误明确；用新渲染检查层级、长原因和窄窗。已验证的原生操作/动效作为保持矩阵。
- 不证明站点未来可达、模型结论正确或用户已逐项实测；人工验收继续按用户决定暂通过，报告问题后重新打开对应项。
