# Apple 设计原则与来源反馈更新

本轮已把 Apple 设计原则适配进 TheRSS 项目规范，并修复来源状态读取遗漏 Discover 历史的问题。Sources 现在显示最新有效本地记录的状态、时间、上下文和原因；原生与 Web 侧栏的常驻 attention 提示已移除。没有新增动画库、全局 skill 或数据库迁移。

## 用户可见变化

- 来源详情先显示名称、状态、记录时间和原因，优先级及其他辅助元数据在后面。Failed 与 Partial 分别计数，可以通过 Failed or partial 筛选。
- Latest search 指已保存的搜索会话时间；Last source read 指来源读取。No matches 表示该次查询没有匹配项，No items 表示来源窗口没有返回条目。它们都不是来源失效。
- 缓存内容与最近一次观察单独说明。旧记录不再被当成当前可用性；无日期记录明确显示时间未知。
- Discover 的反馈仍围绕当前搜索展开，保留逐来源详情、取消和未完成来源重试。直接编辑、原生滚动、单击/Return 阅读及本地查询保持不变。

## 修复依据与边界

旧 Dashboard 只读取 `source_run`；Discover 写入 `discover_source_run`，导致后续搜索无法更新 Sources 的显示。现场只读检查发现，旧的三项 partial 来自 8 月 19 日，而 9 月 7 日的搜索已经有不同结果。这是本地记录一致性问题，不证明任何站点未来可达。

新增的只读投影比较来源读取和每个来源最近的有效 Discover 观察，按已记录时间选取；相同时间保留来源读取。Discover 的未选择、取消和无效日期不会覆盖有效历史，同时间搜索以会话 ID 确定顺序。保留旧 Today 的刷新时间语义。回归测试核对所有表的内容在读取前后完全相同，异常说明继续限制长度并过滤现有凭据和私有路径模式。
