# 研究工作台界面与集成参考

核对日期为 2026-11-06。以下交互建议依据产品官方文档，并结合 TheRSS 的本地数据与证据规则。

| 参考             | 已核对的做法                                                                                                                                                                                                                                                                      | TheRSS 的应用                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Apple macOS      | 侧栏负责主要区域导航。分栏保留高亮选择，支持调整宽度和恢复隐藏面板。[Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars?changes=_11) · [Split views](https://developer.apple.com/design/human-interface-guidelines/split-views?changes=_6)          | 让每日入口容易发现。宽窗口保持论文列表和详情并排，窄窗口在两者之间切换。返回时保留所选论文、筛选和列表位置。                           |
| Zotero           | 订阅流支持手动刷新、标记已读或未读，并通过独立动作把条目加入文库。文档展示了订阅流与文库的界面。[Zotero Feeds](https://www.zotero.org/support/feeds#reading_feeds)                                                                                                                | 将浏览处理、保存到 TheRSS 和写入 llm-wiki 分成三个动作。列表显示简短的处理状态，论文详情显示对应的归档动作。                           |
| Readwise Reader  | Web 阅读界面提供可见的焦点指示和键盘阅读、标记、批注等操作。[Readwise Docs](https://docs.readwise.io/reader/docs/faqs/highlights-tags-notes#can-i-highlight-andor-make-annotations-using-the-keyboard)                                                                            | 复用 TheRSS 的方向键选中、Return 打开、保存和撤销。新增筛选或批量操作时，保留焦点反馈，并避免与文本输入冲突。                          |
| Semantic Scholar | 用户可按文库主题启用 Research Feed。推荐按日刷新，用户可查看历史推荐并标记不相关条目。[Semantic Scholar Research Feeds FAQ](https://webflow.semanticscholar.org/faq/create-research-feeds) · [查看 Research Feeds](https://webflow.semanticscholar.org/faq/access-research-feeds) | 按研究方向保留可重复使用的本地筛选规则，并支持回看批次。优先显示命中的词和规则。用显式“不相关”反馈来评估后续调优。                     |
| Obsidian         | `obsidian://open` 可以用库名或库 ID 加文件路径打开笔记，也可以用绝对路径。URI 参数需要编码。[Obsidian URI](https://obsidian.md/help/uri)                                                                                                                                          | 复用主进程已验证的打开动作。根据论文身份重新解析库内目标，向用户显示笔记、仅记录、缺失或冲突。写入继续走独立预览和确认。               |
| arXiv            | 官方公告以美国东部时间发布。发布安排跨周末，节假日或其他情况可能推迟公告。[公告日程](https://info.arxiv.org/help/availability.html#announcement-schedule) · [推迟公告](https://info.arxiv.org/help/availability.html#on-deferred-mailings)                                        | 分开显示本地日期、实际公告批次、论文原始日期和最后检查时间。来源未到、无匹配、部分结果和获取失败应有各自的反馈，较早的批次保留其日期。 |

TheRSS 现有渲染参考为 [原生论文详情截图](../2026-10-28-llm-wiki-status/native-status.png) 和 [Web Discover 截图](../../images/therss-discover.png)。两张图均为历史固定样本。当前原生 Sources 可读最新 arXiv 来源日，原生 Discover 与 Saved 可从论文详情查看 llm-wiki 状态。Web 详情支持入库预览。相关实现见 [Sources](../../../src/main/appkit/sources.ts#L349)、[原生 llm-wiki 状态](../../../src/main/appkit/wikiStatus.ts#L124) 和 [Web 详情](../../../src/renderer/src/DiscoverResultWorkspace.tsx#L259)。
