## 获批交互

1. Sources 顶部增加 My sources · N/22 入口，打开默认检索来源管理 sheet。
   全部 22 个现有来源，沿用现有五组；每项为复选框、真实来源名称和既有用途说明。
   支持按名称/用途/分组查找及 Only selected。查找不改研究问题、不联网、不改隐藏项选择。
   批量动作是 Select shown / Clear shown，只作用当前可见项；分组标题显示已选数/总数，
   不再增加语义重叠的整组选项。Restore all 只修改未保存草稿。
   底部选中数量、Cancel、Save default sources；0 项禁止保存，就近解释至少选择一个。
   Cancel / Escape 不保存，返回入口焦点。保存成功才更新默认偏好，不启动检索。
2. Discover 将来源入口明确为本次检索来源（例如 Sources for this search · N/22）。
   复用选择器展示，区分本次模式与默认模式；提供 Apply to this search、Cancel、Use defaults。
   单次编辑有独立草稿，Apply 只修改本次组合，Cancel 不修改；不会写回默认偏好。
   仍需点击 Search，才只请求本次明确选中的来源。
3. SQLite 归属的共享默认来源偏好：Native 和 Web 使用同一份设置与主进程校验。
   不存到 NativePreferences 布局文件，也不用 localStorage 作为产品事实来源。
   原型 localStorage 仅用于演示，不是实现架构。

## 状态与持久化规则

- 首次启用：有上次持久搜索会话且有效来源非空时，采用该会话的来源组合初始化默认；
  没有有效历史时全部 22 个。此初始化不执行检索。
- 有独立偏好之后：启动时本次草稿从默认组合初始化；加载旧结果不能再覆盖它。
  旧结果继续标明原会话范围；本次来源不同时提示下次搜索后生效。
- Sources 保存新默认：当前本次组合仍等于旧默认且没有活动任务时，同步本次组合；
  若本次已临时调整或有活动任务，则保留草稿和任务，提示未来生效并允许 Use defaults。
- 临时组合保持到用户再次调整、Use defaults 或重启；搜索完成时不突然跳回另一组合。
- 改默认不能清理或隐藏 Saved/旧结果，不能改变进行中的任务。
- 历史搜索重试沿用那次的计划与原失败/部分/取消来源，不使用新默认，也不覆盖当前草稿。
- Sources 的单独浏览/明确刷新保持原行为；Daily Papers 仍读已有本地日报。
  这是 Discover 的默认组合，不是全局网络禁用开关；不要增加自动订阅或后台刷新。
- 保存失败保留草稿并可重试；偏好读取失败须明确提示，不能静默全选再搜索。
- 保存边界校验 0/1/22 项、非法/未知/重复 ID；记录并测试重复 ID 的明确处理规则。
  未来新增来源不自动加入保存组合；不可用的旧 ID 提示检查，有效集合为 0 时禁止检索。
