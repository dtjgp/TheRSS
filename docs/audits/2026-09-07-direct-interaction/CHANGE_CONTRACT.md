# 直接编辑与直觉操作契约

## Feature Intake

- 用户反馈：搜索前需要点击 Edit search 属于多余步骤；要求找出同类设计并改为更直接的操作。
- 当前证据：原生 Discover 在载入/完成搜索后移除输入框，改用摘要标签、Edit search 和 Done editing；已有列表单击/Return 打开能力却另设 Read selected；详情已有滚动区域仍截断摘要；本地查找需要提交按钮，且原生结果已支持单击打开却重复提供 Open in TheRSS；Sources 打开后保留重复的 Open cached content。
- 目标：直接定位和编辑问题，直接阅读/打开记录；沿用现有原生系统控件、字体、配色与 3/2/7 密度和动效选择。
- 选择：移除无独立作用的中间状态，保留明确的模型调用、网络刷新、保存和外部写入动作。拒绝把所有动作自动化或引入另一套设计系统。
- 成本与边界：UI 状态与离线测试变更；本地搜索增加有界防抖请求，不引入模型/网络、依赖、数据库迁移或新 IPC。
- 停止条件：下方验收及当前构建/安装/PR 交付完成；不以新功能扩展替代本次交互修复。

## Capability Contract

### D1 搜索框直接编辑

原生 Discover 的列表工作区始终显示带可见标签和原生边框的 Research question 输入框及一个 Search 操作；移除 Edit search、Done editing 与不可编辑的查询替身。编辑不发起搜索，旧结果与未提交的新问题清晰区分；来源和执行端改变同样标明草稿状态。来源选择统一使用 Sources 按钮，零选中状态删除重复的 Choose sources 按钮，保留原因说明。运行期间禁止修改当前运行输入，取消/失败保留问题与既有结果。

单栏阅读仍通过 Back 返回保留的列表及搜索框，以维持窄窗阅读空间。Web 回退已直接显示输入框，保留其优点并补齐未提交草稿说明与运行中输入边界。

两个界面的主要执行按钮统一为 Search；Web 的 Expand and search / Expanding and searching 是同一执行动作的旧措辞，改为 Search / Searching，不影响模型规划与来源状态。

### D2 列表直接打开

Discover、Saved、Sources、Analytics 的原生列表继续单击/Return 打开，移除重复的 Read selected。窄窗保留 Back、原列表位置、选择、阅读滚动和键盘焦点；Sources/Analytics 的真实载入逻辑走列表激活回调，不依赖已删除按钮。

### D3 摘要直接阅读

Discover/Saved 的原生和 Web 详情展示完整的已获取摘要，使用既有阅读滚动区域；删除 Show full summary / Read full summary / Show less / Collapse summary 及截断状态。标题列表仍可截断以便扫描。不得把摘要称为全文。

### D4 本地查找即时响应

在原生与 Web 本地查找框输入合法的 2–200 字符后，经过约 250 ms 防抖自动查找本地索引；Enter 可立即提交。删除 Search 按钮。输入继续可编辑，取消过时请求的 UI 回写，清空或无效短查询清空过时结果；关闭后不再更新界面。

原生搜索结果已有单击/Return 打开准确本地记录的能力，保留并移除重复的 Open in TheRSS 按钮；Open original 保留为独立的外部网站操作。Web 保留现有标题链接行为，不在本轮新增历史记录路由。所有检索均使用现有有界、只读本地 API。

### D5 来源入口去重

来源列表单击/Return 已打开缓存并按既有规则读取内容，删除其重复的 Open cached content 按钮。保留 Refresh content、Open source website、错误状态和已有缓存，不让键盘移动焦点隐式触发网络刷新。

## Uncertainty Reducer

- 类别：跨工作区交互调整。
- 当前截图与代码明确复现编辑门槛；原生表格 mouseDown/Return 和 fixture 回归确认直接打开已存在。
- 使用确定性 HTML 交互原型先检查搜索框定位、未提交草稿和直接结果激活；真实原生实现随后用隔离 fixture 检查控件、焦点、中文输入和宽窄布局。原型不作为真实来源或最终原生性能证据。

## Frozen Acceptance Contract

- RED：恢复与完成搜索后输入框仍应存在；直接修改不改变旧结果或触发模型；不存在 Edit/Done；新问题/选源/执行端草稿明确。
- RED：四个列表无 Read selected，激活仍进入正确记录；长摘要尾部直接可读，无展开按钮。
- RED：本地查询不依赖按钮，防抖、短查询、清空、异步乱序、错误及关闭均正确；结果激活使用准确 target。
- Sources 无重复缓存按钮，点击/Return 与刷新/外部打开各自保留原职责。
- 现有测试中要求隐藏输入、截断摘要、必须点提交/打开按钮的断言，依照本契约更新；保留全部数据、键盘、取消、证据和副作用验证。
- 验证：有意义的 RED/GREEN、`npm run check`、受影响 Electron E2E、原生完整流程和宽/窄/明暗截图；模型与来源不新增实时调用。
- 交付：保留现有应用/数据库备份后安装，验证数据与构建一致，沿现有分支和草稿 PR #49 交付；不合并或发布 Release。
- 人工验收：记录本次用户反馈及修复，保留真实体验复验待反馈，不由助手预填通过。
