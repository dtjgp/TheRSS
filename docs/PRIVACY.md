# TheRSS 隐私说明

TheRSS 是本地优先的单用户应用。当前代码没有账号同步、广告、遥测 SDK 或自动上传研究数据库的功能。它使用用户明确选择的网络服务完成检索与分析。

## 本机保存什么

本地 SQLite 保存研究背景、问题、检索计划、来源记录、收藏状态、分析内容及其来源与模型信息。模型配置中的密钥以操作系统保护的密文保存，不向界面、MCP 或笔记导出返回明文。

研究背景、问题和分析正文属于普通本地数据，不是加密保险箱。使用本机账号和磁盘保护措施管理这些内容；不要把密码或令牌作为研究背景输入。

默认数据位置为 `~/Library/Application Support/therss/`。本地安装器在替换应用前保存数据库备份和安装回执。备份仍可能含有研究内容及密钥密文，应与主数据库同样保护。

## 哪些操作会联网

| 操作            | 可能离开设备的数据                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| Discover        | 研究问题和已启用的 Personal context 交给所选模型或本地代理；来源网站接收经过验证的检索词或固定来源请求 |
| Analyze         | 选中记录的摘要和相关元数据交给所选执行端                                                               |
| Test connection | 当前模型配置及其所需认证信息发给所选模型端点                                                           |
| 打开或刷新来源  | 对内置来源地址发出请求；网站可以看到正常的网络连接信息                                                 |
| Open original   | 在浏览器打开对应网站，适用该网站及浏览器的隐私设置                                                     |
| llm-wiki 预览   | 下载官方 arXiv PDF，并可能通过已配置的 Codex 服务分析有界论文文本                                      |

Codex / Claude Code 的账号、登录与服务数据政策由相应产品管理。自定义模型服务的数据保留及费用由其提供方决定。TheRSS 不保证第三方会如何保存已经发送给它们的数据。

本地查找、切换筛选、阅读缓存、收藏及 Data Analytics 不需要模型或来源网络请求。应用不会在启动时自动把问题发送到全部来源。

## 写入、删除与反馈

取消收藏会改变分拣状态，不会自动删除对应搜索历史或分析。清除 Personal context 关闭后续背景应用，但不会抹去此前已经生成的检索计划。清除凭据不影响已经发送给服务方的数据。

llm-wiki 写入须经目标与文件路径预览以及最终确认。MCP 当前只提供只读研究接口。

删除全部本地研究数据前，请退出应用并确认是否保留备份。删除数据目录也会失去配置和历史；旧备份需另行管理。不要在应用运行时直接覆盖数据库。

向公共问题区提供日志或截图前，请移除密钥、私人研究问题和未公开论文内容。技术边界见 [安全说明](SECURITY.md)。
